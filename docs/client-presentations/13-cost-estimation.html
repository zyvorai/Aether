Supported Providers

Aether includes built-in pricing models for five major cloud providers, with per-resource cost breakdowns.

☁

AWS

EC2 instance pricing based on vCPU and memory. Includes EBS storage, network egress, and ALB load balancer costs. Based on us-east-1 on-demand rates.

  • CPU: $15.00/core/month
  • Memory: $4.00/GB/month
  • Storage: $0.10/GB/month
  • GPU: $350.00/unit/month
☁

Azure

Virtual Machine pricing with Azure Disk Storage and bandwidth. Based on East US standard tier pricing.

  • CPU: $14.00/core/month
  • Memory: $3.50/GB/month
  • Storage: $0.12/GB/month
  • GPU: $320.00/unit/month
☁

GCP

Compute Engine pricing with Persistent Disk and network costs. Based on us-central1 on-demand rates.

  • CPU: $13.50/core/month
  • Memory: $3.75/GB/month
  • Storage: $0.08/GB/month
  • GPU: $300.00/unit/month
☁

DigitalOcean & Linode

Droplet and Linode pricing with block storage. Simpler pricing models with flat per-resource rates.

  • DO CPU: $12.00/core/month
  • DO Memory: $3.00/GB/month
  • Linode CPU: $11.00/core/month
  • Linode Memory: $2.50/GB/month

Cost Breakdown Structure

CostEstimate Fields

FieldDescription
providerCloud provider name
cpu_cost_monthlyMonthly cost for CPU cores
memory_cost_monthlyMonthly cost for RAM
storage_cost_monthlyMonthly cost for disk storage
total_monthlySum of all monthly costs
total_hourlytotal_monthly / 730 hours
currencyAlways USD

Resource Parsing

# Your workload spec
requirements:
  cpu: "4"          # 4 cores
  memory: 16Gi      # 16 GB RAM
  storage: 100Gi    # 100 GB disk
  gpu:
    count: 1
    vendor: nvidia

# Aether calculates:
#   CPU:     4 cores x $15.00  = $60.00/mo
#   Memory:  16 GB   x $4.00   = $64.00/mo
#   Storage: 100 GB  x $0.10   = $10.00/mo
#   GPU:     1 unit  x $350.00 = $350.00/mo
#   ---
#   Total: $484.00/mo ($0.6630/hr)

Cost-Aware Scheduling

Aether's Decision Engine can factor cost into runtime selection, choosing the most economical target that meets your workload requirements.

💰

Automatic Cost Optimization

When the runtime preference is set to auto, the Decision Engine evaluates cost alongside isolation requirements, scaling needs, and hardware constraints to select the optimal runtime.

📊

Budget Constraints

Set maximum monthly budgets per workload. Aether will warn when a deployment would exceed the budget and suggest cheaper alternatives.

📈

Scaling Cost Projection

When using HPA, Aether projects costs at minimum, target, and maximum replica counts so you can understand the cost envelope before deploying.

🔍

JSON Output for Analysis

Export cost estimates as JSON for integration with financial dashboards, FinOps tools, and custom reporting pipelines.
