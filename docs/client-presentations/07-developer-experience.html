Compose & Watch

Deploy entire stacks with dependency ordering, then auto-redeploy on file changes.

Multi-Workload Compose

aether-compose.yaml

apiVersion: aether/v1
kind: Compose
metadata:
  name: my-stack
spec:
  workloads:
    database:
      template: database
      image: postgres:16-alpine
      env:
        - name: POSTGRES_DB
          value: appdb
      volumes:
        - pgdata:/var/lib/postgresql/data

    cache:
      template: cache
      image: redis:7-alpine
      depends_on: []

    api:
      template: rest-api
      image: my-registry/api:latest
      ports:
        - containerPort: 3000
          hostPort: 3000
      depends_on:
        - database
        - cache
      env:
        - name: DATABASE_URL
          value: postgres://database:5432/appdb
        - name: REDIS_URL
          value: redis://cache:6379

    frontend:
      template: web-app
      image: my-registry/frontend:latest
      ports:
        - containerPort: 80
          hostPort: 8080
      depends_on:
        - api

Deploy the Stack

$ aether compose up

aether exec

Execute commands inside a running workload container.

$ aether exec my-web-app -- sh

# Now inside the container
/ $ ls /usr/share/nginx/html/
index.html  50x.html  assets/

/ $ cat /etc/os-release
NAME="Alpine Linux"
VERSION_ID=3.19.1

/ $ exit

# One-shot command
$ aether exec my-web-app -- cat /etc/hostname

aether port-forward

Forward local ports to workload ports for debugging.

$ aether port-forward my-web-app 8080:80

Forwarding localhost:8080 → my-web-app:80
  Press Ctrl+C to stop

# In another terminal:
$ curl http://localhost:8080
<html>Welcome to nginx!</html>

# Forward multiple ports
$ aether port-forward my-api \
    3000:3000 \
    9229:9229   # Node.js debugger

JSON Schema for IDE Validation

Get real-time validation and autocomplete in VS Code, IntelliJ, and Neovim.

# Export the workload schema
$ aether schema workload > \
    aether-workload-schema.json

# VS Code settings.json
{
  "yaml.schemas": {
    "./aether-workload-schema.json": [
      "workload.yaml",
      "aether-compose.yaml"
    ]
  }
}

# Now your editor validates:
#  ✓ Required fields
#  ✓ Value types and ranges
#  ✓ Enum values (runtime, strategy)
#  ✓ Autocomplete on properties
