Unique Advantages

Aether is not just another deployment tool — it is the only control plane that unifies four runtimes behind a single declarative spec.

📄

One Spec, Four Runtimes

Write your workload YAML once. Aether deploys it to Podman for dev, Kubernetes for staging, KubeVirt for legacy apps, and Metal3 for GPU workloads — without rewriting a single line.

🔄

Migration Engine

16 distinct runtime-to-runtime migration paths with blue-green, rolling, and immediate strategies. Move workloads between any two runtimes with zero downtime and automatic rollback.

⚡

Decision Engine

The built-in scheduler evaluates CPU, memory, GPU, cost, and affinity to automatically select the optimal runtime. Override when you need to, trust it when you do not.

📊

Full Observability Stack

Drift detection, SLA compliance, metrics, health monitoring, and audit trails — all built into the control plane. No external Prometheus, Grafana, or Vault required to get started.

Other tools manage one runtime well. Aether manages the choice between runtimes — and makes that choice reversible at any time.

Migration from Existing Tools

Aether is designed to complement, not replace. Adopt incrementally alongside your existing tooling.

Migration Paths

1

From Docker Compose

Import your docker-compose.yml using aether compose import. Aether converts services to workload specs, preserving port mappings, environment variables, and volume mounts. Run on Podman first, then migrate to Kubernetes when ready.

2

From kubectl / Helm

Start by managing new workloads with Aether specs while keeping existing Helm releases. Gradually migrate services by creating Aether specs and using the migration engine to move from Kubernetes to any other runtime (or keep on Kubernetes with unified management).

3

From Nomad

Translate HCL job files to Aether YAML specs. Aether's scheduler provides similar constraint-based placement but adds cross-runtime migration and built-in drift detection that Nomad lacks.

4

From Custom Scripts

Replace shell scripts with declarative YAML specs. Gain idempotent deploys, automatic rollback, state tracking, and audit trails. The initial conversion is the last time you write deployment logic.

Start Deploying Across Every Runtime Today

Aether is open source, written in Rust, and designed for production. One spec, four runtimes, zero lock-in. Install in seconds, deploy in minutes.

# Get started in 3 commands
$ cargo install aether
$ aether init my-project
$ aether run --spec workload.yaml

# Migrate from Docker Compose
$ aether compose import docker-compose.yml
$ aether run --spec imported-workload.yaml

# Move to Kubernetes when ready
$ aether migrate my-app --from podman --to kubernetes \
    --strategy blue-green
