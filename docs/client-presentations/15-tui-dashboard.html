TUI Features

The Aether TUI provides a unified operational view of every workload across Podman, Kubernetes, KubeVirt, and Metal3 in a single terminal screen.

📊

Real-Time Monitoring

The dashboard auto-refreshes every 5 seconds, querying each runtime adapter for current workload status. Running, pending, failed, and stopped states are displayed with color-coded indicators.

🔍

Search & Filter

Type / to activate the search bar. Filter workloads by name in real time. The search filter narrows the workload list as you type, making it easy to find specific services in large deployments.

📋

Resource Detail Panel

Select any workload to see its full details: runtime, state, readiness, restart count, age, image, ports, and resource limits. The detail panel updates in sync with the workload list.

📜

Log Viewer

Press Enter on a workload to open the log viewer. Stream logs in real time with automatic scrolling. Press Esc to return to the dashboard.

Keyboard Navigation

The TUI is fully keyboard-driven. No mouse required — navigate, search, view logs, and manage workloads with a consistent set of key bindings.

Key Action Context
Up / Down / k / j Navigate workload list Dashboard
Tab Switch focus between panels Dashboard
Enter Open log viewer for selected workload Dashboard
/ (slash) Activate search/filter bar Dashboard
Esc Close search bar or return to dashboard from logs Search / Logs
r Force immediate refresh Dashboard
q Quit the TUI Any

Vim-Style Navigation

The TUI supports both arrow keys and Vim-style j/k navigation for moving through the workload list. This makes it natural for developers who use Vim, Neovim, or terminal-centric workflows.

The TUI is designed for operators who live in the terminal. Every action is one or two keystrokes away, with no mode confusion or hidden menus.

Auto-Refresh & Web Dashboard

The TUI refreshes automatically every 5 seconds. For browser-based monitoring, Aether also offers a web dashboard.

🔄

Auto-Refresh (5 seconds)

The TUI polls all runtime adapters every 5 seconds for fresh status data. Each runtime is queried concurrently — Podman via CLI, Kubernetes via the kube API, KubeVirt and Metal3 via CRD watches.

# Launch the TUI
$ aether tui

# The dashboard refreshes every 5 seconds
# Press 'r' to force an immediate refresh
# Press 'q' to quit
🌐

Web Dashboard Alternative

For teams that prefer a browser-based interface, Aether includes a web dashboard served on port 5090 with a login page and REST API.

# Start the web dashboard
$ aether serve
Server running at http://localhost:5090

# Or specify a custom port
$ aether serve --port 8080
Server running at http://localhost:8080

# The web dashboard provides:
#   - Workload list with status
#   - Real-time log streaming
#   - REST API for automation
#   - Login authentication
