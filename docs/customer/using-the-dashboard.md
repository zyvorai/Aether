# Using the Dashboard

Aether is organized by navigation groups (sidebar, desktop nav, or CLI command groups). Use search / command palette when available.

## Surfaces

| Need | Path |
|------|------|
| Command Center | `/` |
| Fabric | `/fabric` |
| Migrations | `/migrations` |
| Zeus | `/zeus` |
| Settings | `/settings` |

## Browse vs act

Inventory and status views are safe to explore. Mutating actions (deploy, migrate, sign, remediate) follow role gates and confirmation dialogs — review impact first.
