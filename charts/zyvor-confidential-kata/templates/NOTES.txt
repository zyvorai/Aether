Zyvor confidential RuntimeClasses installed.

Prerequisites:
  - Confidential Containers (coco) Helm release in namespace coco-system
  - TEE-capable nodes labeled (SEV-SNP / TDX)

Verify:
  kubectl get runtimeclass | grep -E 'kata-clh|kata-qemu'
  kubectl get pods -n coco-system

Ragnarok hub: /confidential
Aether: set runtimeClassName to a class from this chart (e.g. kata-clh-snp).

If pods fail with unknown runtime handler, set values to match `kubectl get runtimeclass` handlers
and upgrade: helm upgrade zyvor-coco ./charts/zyvor-confidential-kata -f my-values.yaml
