Aether has been deployed!

Access the API:
{{- if eq .Values.service.type "NodePort" }}
  http://<node-ip>:{{ .Values.service.nodePort }}
{{- else }}
  kubectl port-forward svc/{{ include "aether.fullname" . }} 8080:{{ .Values.service.port }} -n {{ .Release.Namespace }}
  http://localhost:8080
{{- end }}

Check trial status:
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "aether.fullname" . }} | head -5

After the 30-day trial, contact sales@zyvor.dev for a licence key:
  kubectl create secret generic aether-license \
    --from-literal=license.key="<your-key>" \
    -n {{ .Release.Namespace }}

  helm upgrade {{ .Release.Name }} oci://ghcr.io/hypersdk/charts/aether \
    --reuse-values \
    --set license.existingSecret="aether-license" \
    -n {{ .Release.Namespace }}
